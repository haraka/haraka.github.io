# haraka.github.io

Source for [haraka.github.io](https://haraka.github.io), built with [Docus](https://docus.dev) on Nuxt.

Pages live in `content/`. Pushes to `master` are built and deployed to the `gh-pages` branch by GitHub Actions.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run generate
npm run preview
```

The static site is written to `.output/public`.
