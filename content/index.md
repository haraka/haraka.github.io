#title
Haraka

#description
_A modern, high performance, flexible SMTP server_. Haraka is an open source SMTP server written in Node.js which provides extremely high performance coupled with a flexible plugin system allowing JavaScript programmers full access to change the behaviour of the server. It is used heavily in some high traffic sites - see the [Known Users](/users) page for testimonials.
